Politique de confidentialité

C-Patrimoine · mise à jour le 24 novembre 2026

C-Patrimoine est une app gratuite et sans publicité qui permet de suivre ses biens immobiliers (prix d'achat, prêts, estimations) et d'en estimer la valeur à partir de statistiques publiques. Elle est conçue pour collecter le moins de données possible.

Où sont vos données ?

Tout ce que vous saisissez dans C-Patrimoine (biens, adresses, prix, prêts, estimations, parts de propriété, noms des membres de la famille) est enregistré :

  • sur votre iPhone ;
  • dans votre compte iCloud, le service d'Apple, pour la synchronisation entre vos appareils ;
  • et, si vous le décidez, partagé avec les seules personnes que vous invitez, via le partage iCloud d'Apple.

Le développeur de C-Patrimoine n'a pas accès à ces données et ne les reçoit à aucun moment. Leur stockage est régi par les règles de confidentialité d'Apple.

Ce que l'app connaît de vous

  • Votre identifiant iCloud (un code anonyme fourni par Apple), uniquement pour accéder à vos données et à celles partagées avec vous.
  • Si vous partagez votre patrimoine, les personnes invitées voient votre nom ; vous voyez le nom et l'adresse ou le numéro utilisés pour les inviter, comme pour tout partage iCloud.

C-Patrimoine ne demande ni compte, ni mot de passe, ni localisation, ni contacts, ni photos.

Données de marché

Les estimations utilisent des statistiques publiques de prix (Statbel pour la Belgique, INSEE pour la France) incluses dans l'app. Aucune information sur vos biens n'est envoyée pour les calculer.

Ce que C-Patrimoine ne fait pas

  • Aucun suivi publicitaire, aucune mesure d'audience, aucune revente de données.
  • Aucun partage avec des tiers, en dehors d'Apple (iCloud).

Exporter ou supprimer vos données

  • Exporter : Plus → « Exporter en CSV » ou « Sauvegarde complète (JSON) ».
  • Tout supprimer : Plus → « Supprimer toutes mes données ». Vos biens sont effacés de l'iPhone et de votre iCloud, et les personnes invitées perdent l'accès.
  • Personne invitée : Plus → « Ne plus voir ce patrimoine ».
  • Vous pouvez aussi gérer les données des apps dans Réglages → [votre nom] → iCloud.
